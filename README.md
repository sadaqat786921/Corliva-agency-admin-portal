# CORLIVA — Agency Admin Portal

Clickable prototype of the Agency Admin web portal for the CORLIVA home care platform.

**Pages:** Sign in · Forgot password · Agency set-up (4 steps) · Dashboard · Users & Roles · Agency & Branches · Services & Lists · Rules & Requirements · Notifications · Referrals · Clients · Schedule · Visit Approvals · Incidents · Reports · Audit History · Settings

```
npm install
npm run dev
```

Sign in with any email and a password of 8+ characters. See `AGENTS.md` for the design rules.
